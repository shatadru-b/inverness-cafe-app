Reservation section — offline archive

This file is not part of the live site build. It is a restore guide + static HTML snapshot so reservations can be turned back on without rewriting the feature from scratch.

How to re-enable (single prompt / one change)

  1. Set RESERVATIONS_ENABLED = true in lib/features.js
  2. Confirm these still exist (they were never deleted):
    • components/sections/ReserveSection.js
    • components/sections/reserve.module.css
    • app/reserve/page.js
  3. When the flag is true, the app already wires:
    • Homepage: <ReserveSection />
    • Navbar item: Reserve → /reserve/
    • Footer: Reservations link
    • Hero secondary CTA: Book a Table
    • About CTAs: Book a Table
    • Sitemap: /reserve/
    • Public /reserve/ page (no redirect)
  4. Run npm run build and deploy.
